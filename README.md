# 🏠 Dotfiles

My personal configuration files for Arch Linux with an optimized development environment.

## 📋 Contents

Configs are split into [GNU Stow](https://www.gnu.org/software/stow/) packages, one per context:

- **base**: shell (bash/ble.sh), terminal (kitty), editors (nvim), file manager ([Yazi](https://github.com/sxyazi/yazi)), tmux, and other Arch-agnostic tooling
- **caelestia**: Hyprland + [caelestia](https://github.com/caelestia-dots/shell) shell setup
